# Influenza Vaccine Trial — Raw to SDTM, ADaM and TLF

Dual-programmed (SAS production, R independent QC) pipeline for a synthetic randomized, placebo-controlled influenza vaccine trial: EDC-style raw data, SDTM (IG 3.4), ADaM, four TLFs, Define-XML 2.1 and Pinnacle 21 validation. Reactogenicity (solicited reactions graded per the FDA 2007 toxicity scale) and HAI immunogenicity (GMT, GMFR, seroconversion, seroprotection) are the main logic.

## Data

Everything is synthetic. No real trial data is used. This is a programming exercise, not a replication of any study, and has no connection to a regulatory submission.

- Study VAXF101: 240 adults (18-60) randomized 2:1 to a trivalent inactivated vaccine (VAXF-101) or placebo, single 0.5 mL dose, 91 days, 5 visits. Design in [docs/study-design.md](docs/study-design.md).
- Raw data: 12 Rave-style form CSVs generated by Python scripts (`python/make_raw.py`), seed fixed. Includes screen failures, unit mix-ups, partial dates and dropouts. Not committed; rerun the script to rebuild.
- Python is used only for generating the synthetic raw data and building specs/define.xml. All SDTM, ADaM and TLF programming is in SAS, with independent QC in R.
- The generator's HAI titers and reaction rates were calibrated to publicly posted summary results of a comparable seasonal influenza trial (ClinicalTrials.gov NCT03095599). Strains are renamed A/B/C; the product and study names are made up.

## Approach

1. Mapping spec drives both programs: `specs/sdtm-spec.xlsx`, `specs/adam-spec.xlsx` (kept local).
2. SAS programs in `sas/` (sdtm, adam, tlf, macros), independent R programs in `r/`. Outputs compared with `{diffdf}`; TLF cells compared one by one.
3. `python/make_define.py` builds Define-XML 2.1 for SDTM and ADaM.
4. Pinnacle 21 Community validation, remaining findings explained below.

SDTM (15): DM, DS, EX, SV, IE, VS, AE, CE, FACE, IS and trial design TA, TE, TV, TI, TS.
ADaM (5): ADSL, ADIS, ADFACE, ADCE, ADAE.

ADaM notes:
- ADIS: titers below the LLOQ (`<10`) are set to LLOQ/2 for GMT and GMFR. Seroconversion is baseline < 10 and Day 22 >= 40, or baseline >= 10 and a 4-fold rise.
- ADFACE/ADCE: daily grades from diameter and oral temperature, maximum grade per window. ADCE is cross-checked against ADFACE.
- ADAE: unsolicited AEs through Day 22 (`ANL01FL`), SAEs through Day 91 (`ANL02FL`).
- Immunogenicity population: dosed, valid Day 1 and Day 22 HAI result, Day 22 within study day 19-25.

## TLF

| Table | Content |
|---|---|
| 14-1.01 | Populations, disposition, demographics |
| 14-2.01 | HAI GMT, GMFR, seroprotection, seroconversion by strain and arm |
| 14-3.01 | Solicited local and systemic reactions by maximum grade (30 min, 7 days) |
| 14-3.02 | Unsolicited AEs through Day 22, SAEs through Day 91 |

Example, Strain A (immunogenicity population, vaccine n=142, placebo n=70): Day 22 GMT 118.8 vs 11.0, GMFR 12.1, seroconversion 75.4% vs 0%. Unsolicited AEs 15.1% vs 11.4% (safety population 159 vs 79). The data are synthetic, so these numbers say nothing about a real vaccine.

## Pinnacle 21 warnings

Community edition, engine FDA 2508.1, SDTM-IG 3.4 and ADaM-IG 1.3. MedDRA and SNOMED are not configured, so coding checks do not run. The rest are kept on purpose:

| Rule | Domain | Cause |
|---|---|---|
| SD0087, SD2237 | DM | 2 randomized subjects were never dosed (no RFSTDTC, ACTARM differs from ARM) |
| SD1366, SD1375 | DM | 29 subjects have RFENDTC but received no treatment |
| SD1249 | EX | 79 placebo records have EXDOSE 0.5 mL (injection volume, not drug dose) |
| SD1201 | CE | 2,436 no-reaction rows, same test at two time points |
| SD2239 | FA | FATPT differs between the 30-minute check and diary day 1, by design |
| SD1445 | IS | 464 records with multiple ISLOBXFL for the same test |
| SD1204 | AE | AEENDTC after RFPENDTC (post-study recovery date, kept as collected) |
| SD1149 | AE, DM, IS | Expected variables kept empty on purpose (MedDRA hierarchy and codes, death date and flag, reference ranges) |
| SD1076, SD1078 | CE, FA, TS, TV | Optional variables added or empty |
| SD1311-SD2287 | TS | Optional or sponsor-specific trial summary parameters not populated |
| SD1107, SD1111, SD1321 | Global | No LB, SE or SUPPAE in scope |
| AD0047 | ADAE | 10 MedDRA hierarchy variables not available |
| AD9999 | ADaM | SDTM-only datasets are not checked against ADaM rules |
